# Text Classification Using Sparse Features and Contextual Embeddings

A text classification project that compares traditional sparse text representations with contextual embeddings generated by transformer models. Using the AG News dataset, the project evaluates how different feature extraction methods and ML models perform when classifying news articles into four categories: **World, Sports, Business, and Sci/Tech**.

## Project Overview

The project uses 10,000 news articles from the AG News dataset:
- 8,000 training samples
- 2,000 testing samples
- 4 balanced news categories

The main objective is to compare traditional approaches such as Bag of Words (BoW) and TF-IDF with contextual embeddings generated by BERT and DistilBERT.

## Features and Workflow

- **Exploratory Data Analysis** – Examines class distribution, text length, word counts, frequent words, and common bigrams through visualizations.
- **Text Preprocessing** – Applies lowercasing, special-character removal, stopword removal, and filtering of short and numeric tokens.
- **Sparse Feature Extraction** – Generates Bag of Words unigram features and TF-IDF bigram features, each with a vocabulary limit of 5,000.
- **Contextual Embeddings** – Generates text embeddings using the pretrained BERT and DistilBERT models.
- **Dimensionality Reduction** – Applies Truncated SVD and PCA to reduce feature dimensions while retaining useful information.
- **Model Evaluation** – Compares Logistic Regression, Linear SVM, K-Nearest Neighbors (KNN), and KMeans using accuracy, macro F1-score, recall, and precision.
- **Visualizations** – Produces plots for data exploration, feature analysis, dimensionality reduction, and model comparisons.

## Results

The experiments show that contextual embeddings generally perform better than sparse features.

- **Best sparse-feature result:** Logistic Regression with BoW achieved **84.65% accuracy**.
- **Best DistilBERT result:** Linear SVM achieved **88.25% accuracy**.
- **Best BERT result:** Logistic Regression achieved **87.70% accuracy**.
- **Overall observation:** DistilBERT achieved performance comparable to BERT while requiring fewer computational resources. KNN performed better with dense embeddings than with sparse features, while KMeans generally had the lowest classification performance.

## Requirements

- Python 3
- Jupyter Notebook
- Internet connection to download the AG News dataset and pretrained transformer models
- GPU is optional; the embedding notebook automatically uses CUDA when available and otherwise runs on CPU.

## Setup

1. Clone the repository and open the project directory.

2. Create and activate a virtual environment (recommended).

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

   This will install all required packages: `datasets`, `transformers`, `torch`, `numpy`, `scikit-learn`, `nltk`, `seaborn`, `matplotlib`, and `tqdm`.

4. Install Jupyter Notebook if it is not already available:

   ```bash
   pip install notebook
   ```

## Running the Project

Run the notebooks in the following order:

1. **`eda.ipynb`** – Explore the AG News dataset and generate data visualizations.
2. **`sparse_features.ipynb`** – Preprocess the text, create BoW and TF-IDF features, apply dimensionality reduction, and evaluate the models.
3. **`embeddings.ipynb`** – Generate BERT and DistilBERT embeddings, apply PCA, and compare model performance.

Start Jupyter Notebook from the project directory:

```bash
jupyter notebook
```

Open the notebooks in your browser and execute their cells. The `data_loader.py` file loads the AG News dataset and provides the training and testing data used by the notebooks.

The first run may take longer because the dataset and pretrained transformer models need to be downloaded. The embedding notebook also saves generated embeddings as `.npy` cache files so they can be reused in later runs.
